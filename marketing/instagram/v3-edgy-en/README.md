# BLEND — Instagram Edgy Set v3 (English)

The English version of the edgy set — same 12 designs as `../v3-edgy`
(1080×1350, wine/cream/ink/blue, DM Serif Display + JetBrains Mono), copy in
English to match the bl-nd.nl brand voice. The Tikkie post stays a Tikkie —
the audience is still Dutch, the voice is English.

- `posts.html` — all posts at full size, self-contained (fonts embedded)
- `png/` — upload-ready exports + `00-grid-preview.png`

**Usage:** pick one language per feed and stay consistent. English matches the
site and travels further (expats are a target group); Dutch (`../v3-edgy`) hits
harder for tag-a-friend virality. A hybrid also works: English feed, Dutch
captions.

⚠️ **Post 04 (Delete Tinder)** names a competitor. Deliberate guerrilla —
generally fine as comparative advertising, but save it for a moment with
momentum.
